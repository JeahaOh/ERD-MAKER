# 완성도 평가

기준일: 2026-10-21. 사용자가 요청한 백분율에 대한 개발 범위 추정이다. 승인된 [전체 제품 계획](plans/product-reimplementation-plan.md)의 범위는 유지한다.

**전체 eXERD 대체 제품 기준 약 60%(추정 범위 55~65%)다.** 원본 기능/화면의 동등률을 측정한 값, 테스트 통과율, 출시 승인 점수가 아니다. 아래 항목별 추정에 가중치를 적용하면 약 62%이며 작업량·수용 범위의 불확실성을 반영해 60% 수준으로 보고한다. 데이터 손실이나 원본 재열기 실패를 평균 점수로 상쇄하지 않는다.

## 확정된 검증과 미확정 사항

- 10/21 로컬 전체 단위검사 255개·Chrome E2E 19개 통과.
- 네 DB의 독립 모델 37개·SQL 적용/카탈로그/동작 검사 217개 통과. Oracle은 **26ai Free 23.26.3.0.0**이며 Oracle 19c 통과를 뜻하지 않는다.
- Oracle 19c 회사 테스트 절차와 SQL을 제공한다. 실제 회사 실행 결과를 받기 전에는 **19c 미검증**이다.
- 테스트 수는 기능 완성도 분모로 쓰지 않는다. 원본 전체 기능·최종 사용성·OS 설치 수용은 [현재 상태](status.md)와 [기능 추적표](specifications/feature-traceability.md)의 개별 근거로 판단한다.

다음 검증 우선순위: P0 회사 Oracle 19c 결과 확보 → P1 Oracle/MariaDB/MySQL 역공학 및 비교·병합 → P1 출력/인쇄·고급 편집 → P2 실제 OS 설치·장시간/오프라인·업데이트 수용. 일정은 남은 범위와 회사 테스트 결과 확인 후 산정한다.
