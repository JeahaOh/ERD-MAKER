# 모델 내보내기 구현 범위

- 기준: 네이티브 바이너리 그래프에서 만든 `NativeDocumentView`. 내보내기는 원본 문서와 그래프를 변경하지 않는다.
- 목적: 공유 가능한 다이어그램과 테이블 정의서. `.exerd` 전체 속성을 재저장하는 형식은 아니다.
- 구현: `app/src/formats/export/diagram-svg.ts`, `definition-report.ts`.

## API

```ts
diagramSvg(source: NativeExerdDocument | NativeDocumentView, diagramUuid: string): {
  svg: string; width: number; height: number; warnings: string[];
}
exportDefinitionHtml(source, options?: { tableUuids?: string[] }): string
exportDefinitionCsv(source, options?: { tableUuids?: string[] }): string
```

- `NativeExerdDocument` 전달을 권장한다. SVG는 이 경우 선택 다이어그램의 `filteredRelations`도 읽는다.
- 투영을 전달할 때는 `allTables`, `allRelationships`, `allNotes`, `placements` 전체 메타데이터가 필요하다. 선택 다이어그램의 `tables`만으로 다른 다이어그램을 재구성하지 않는다.
- 존재하지 않는 다이어그램이나 선택 테이블 UUID는 오류로 처리한다. 정의서의 빈 선택 배열은 테이블 0개 문서를 만든다.

## SVG

- 스크린샷 없이 원본 배치 좌표를 도형·텍스트·경로로 변환한다. 음수 좌표를 포함한 전체 범위를 `viewBox`로 계산한다.
- 선택 다이어그램의 배치와 메모만 포함한다. 두 끝 테이블이 모두 있는 관계만 표시하며, 숨긴 관계는 네이티브 문서의 `filteredRelations` 기준으로 제외한다.
- 물리명·논리명·스키마·모든 컬럼·자료형·PK/FK·NOT NULL을 표시한다. 외부 다이어그램으로 이어지는 FK도 컬럼 키 표시는 유지한다.
- 관계 방향은 부모 → 자식이다. 양 끝의 `1`, `0..1`, `0..N`, `1..N`을 표시한다. 식별 관계는 실선, 비식별 관계는 점선이다.
- 메모는 HTML 해석 없이 일반 텍스트로 줄을 나눈다. 저장된 높이로 전체 텍스트를 담지 못하면 높이를 늘리고 경고한다. 대상 배치가 같은 도면에 있으면 메모 연결선을 표시한다.
- 사용자 팔레트: Slate `#3A4A5A`, 본문 `#262626`, 배경 `#F9F9F9`, Ice `#8B9FA8`, Teal `#00A19B`, 링크 글자 `#007A76`. 정적 PK/FK·관계·범례는 Slate/본문색을 사용한다. 청록은 HTML 목차처럼 실제 클릭 가능한 링크에만 사용한다.
- XML 예약 문자는 이스케이프한다. 사용자 텍스트를 `style`, URL, 이벤트 속성, `foreignObject`에 삽입하지 않는다. 외부 이미지·폰트·스크립트 요청은 없다.
- XML 1.0에서 표현할 수 없는 제어 문자와 단독 서로게이트는 `⟦U+0001⟧`처럼 표시하고 경고한다. 원본 값은 유지한다.

### SVG 한계

- 원본 수동 관계 경로, 표시 프리셋, 접힌 컬럼, 사용자 서식 전체는 재현하지 않는다. 모든 컬럼을 펼친 결과 테이블이 겹치면 경고하며 위치를 임의 변경하지 않는다.
- 관계는 직교선으로 생성한다. 다른 도형을 피하는 자동 경로 탐색은 지원하지 않아 교차·겹침이 생길 수 있다.
- 같은 테이블이 여러 번 배치되어 있으면 가장 가까운 부모·자식 배치 쌍을 사용하고 경고한다. 원본의 관계별 배치 선택을 보존한다고 주장하지 않는다.
- `NativeDocumentView`만 받으면 숨긴 관계를 검증할 수 없으므로 경고한다.
- 글자 폭은 시스템 글꼴 기준 추정치다. 한글 글꼴이 없는 실행 환경에서 표시 품질은 별도 확인이 필요하다.

## HTML 정의서

- 독립 HTML, UTF-8, 한국어. 스키마·테이블 설명·컬럼 물리/논리명·자료형·NULL·PK·FK 대상/참조 동작·기본값·도메인 경로·설명을 표시한다.
- 키와 인덱스의 컬럼 순서·정렬 방향, 그룹명과 실제 제약 이름, CHECK 이름과 표현식을 별도로 표시한다.
- 도메인 상속은 투영에서 계산한 컬럼 값으로 표시한다. 도메인 경로는 부모 계층을 포함하며 순환을 무한 탐색하지 않는다.
- A4 가로, 테이블별 새 페이지, 인쇄 시 컬럼 헤더 반복. 긴 테이블 전체에 `break-inside:avoid`를 걸지 않는다. 설명 셀은 4열 메타데이터 표의 나머지 3열을 사용한다.
- 사용자 이름·설명·표현식은 HTML 텍스트로 이스케이프한다. 스크립트·입력 폼·외부 자원은 포함하지 않는다.
- 선택한 테이블만 정의서 본문에 포함한다. FK 대상 이름은 참조 설명에 포함될 수 있다. 다이어그램 메모는 정의서에 덧붙이지 않는다.
- DB별 물리 옵션·시퀀스·원본 모든 속성은 이 정의서의 범위에 포함되지 않는다고 문서 본문에 명시한다.

## CSV 정의서

- UTF-8 BOM, CRLF 행 구분, 16열. 컬럼당 한 행이며 컬럼 없는 테이블도 한 행으로 남긴다.
- 모든 셀을 큰따옴표로 감싸고 셀 내부 큰따옴표를 두 번 쓴다. 설명·CHECK의 내부 줄바꿈은 셀 안에서 유지한다.
- 공백 뒤 `=`, `+`, `-`, `@`로 시작하거나 탭/개행으로 시작하는 셀은 앞에 작은따옴표를 넣는다. CSV를 Excel 등에서 열 때 수식으로 실행되는 위험을 줄이기 위한 의도적인 표시 변환이다. 예: `-1` → `'-1`.
- 원본 값 복원용 CSV가 아니다. 따옴표만 감싸는 방식으로 수식 실행이 방지된다고 주장하지 않는다. 프로그램별 CSV 가져오기 설정은 별도 확인 대상이다.

## 검증

- `app/tests/unit/model-exports.test.ts`: 선택 다이어그램 격리, 컬럼 전수, PK/FK/방향/카디널리티, 음수 범위, 메모 크기·제어문자, 실제 숨긴 관계, XSS 입력, HTML 페이지 CSS, CSV 수식·따옴표·개행, 입력 불변성.
- 사용자 파일: 테이블 정의 609개, CSV 컬럼 행 10,045개, 선택 다이어그램 배치·컬럼 수 대조, SVG XML 문법 검사.
- macOS Chrome 합성 2테이블: SVG와 한글 HTML 스크린샷 직접 확인, HTML 스크립트 0개·가로 넘침 없음. 정적 키 색상과 링크 색상 역할도 확인했다. 로컬 근거는 `.analysis/spec/model-export-preview-{svg,html}.png`.
- Chrome 인쇄 PDF 파일 생성까지 확인했다. PDF의 전 페이지 나눔·609테이블 인쇄, 다른 OS의 한글 글꼴 렌더링, Excel의 실제 가져오기 동작은 별도 수용 검증 대상이다.
